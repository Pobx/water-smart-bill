# Product Requirements Document (PRD) — Water Smart Bill

## 1. ภาพรวมผลิตภัณฑ์ (Product Overview)
**Water Smart Bill** คือระบบบริหารจัดการค่าน้ำประปาอัจฉริยะสำหรับองค์การบริหารส่วนตำบล (อบต.) ที่ออกแบบต่อยอดจากโมดูล `tabwater` ในระบบ `pios` เพื่อแก้ปัญหาการจดมิเตอร์น้ำภาคสนามในพื้นที่อับสัญญาณอินเทอร์เน็ต การคำนวณค่าน้ำแบบขั้นบันได การออกใบแจ้งหนี้ผ่านเครื่องพิมพ์ Bluetooth พกพาหน้างาน และการให้บริการข้อมูลแก่เจ้าของบ้านผ่าน LINE LIFF

## 3. ขอบเขตฟีเจอร์หลัก (Key Product Features)

### 3.1 การจัดการข้อมูลพื้นฐาน (Master Data & Household Management)
- บันทึกและแก้ไขข้อมูล **อบต. (`organizations`)**, **จังหวัด/อำเภอ/ตำบล (`provinces`, `districts`, `tambons`)**, และ **หมู่บ้าน/คุ้ม (`zones`, `subzones`)**
- บันทึกข้อมูล **บ้านเลขที่และเจ้าของบ้าน (`users`)** พร้อมรองรับการอัปโหลดรูปโปรไฟล์ (`avatar_url`)
- **Default Avatar Rule:** หากไม่ได้อัปโหลดรูปเข้ามา ระบบต้องแสดงรูป Default Avatar อัตโนมัติ (SVG Initials / Household Default Avatar)
- ขึ้นทะเบียน **มิเตอร์น้ำประปา (`tw_meter_infos`)** ผูกกับเจ้าของบ้าน บ้านเลขที่ และหมู่บ้าน

### 3.2 การกำหนดหน่วยและอัตราค่าน้ำ (Tariff & Billing Period Management)
- กำหนดประเภทมิเตอร์ (`tw_meter_types`) และโครงสร้างอัตราค่าน้ำ (`tw_meter_type_rate_configs`, `tw_meter_type_rate_tiers`) รองรับทั้งแบบอัตราก้าวหน้า (ขั้นบันได) และอัตราคงที่ พร้อมค่ารักษามิเตอร์ (`reserve_fee`) และภาษีมูลค่าเพิ่ม (`vat` 7%)
- เปิดและจัดการงวดบิลประจำเดือน (`invoice_period`)

### 3.3 การบันทึกมิเตอร์น้ำ, คำนวณค่าน้ำ และ AI OCR (Meter Reading & Calculation)
- คำนวณหน่วยน้ำที่ใช้ (`current_meter - last_meter`) และคิดค่าน้ำตามขั้นบันไดอัตโนมัติทันทีที่กรอกเลขมิเตอร์
- **Optional OCR / Vision:** รองรับการถ่ายรูปหรืออัปโหลดรูปหน้าปัดมิเตอร์น้ำเพื่อสแกนอ่านตัวเลขมิเตอร์อัตโนมัติ (Hybrid OCR: On-Device เมื่อ Offline และ Backend OCR API เมื่อ Online) พร้อมให้เจ้าหน้าที่ตรวจสอบ/แก้ไขก่อนบันทึก

### 3.4 การทำงานแบบ Offline-First และการซิงค์ข้อมูล (Offline-First Field Operations)
- ดาวน์โหลดข้อมูลสายจดมิเตอร์ประจำหมู่บ้านและตารางเรทค่าน้ำลงเก็บในเครื่อง (IndexedDB)
- บันทึกเลขมิเตอร์ รูปถ่าย และคำนวณบิลค่าน้ำได้ 100% แม้ไม่มีอินเทอร์เน็ต
- ซิงค์ข้อมูลเข้าเซิร์ฟเวอร์อัตโนมัติหรือกดซิงค์ด้วยตนเองเมื่อมีสัญญาณเน็ต โดยป้องกันบิลซ้ำด้วย `client_reading_id` (`Idempotency-Key`)

### 3.5 การออกบิลผ่านเครื่องพิมพ์ Bluetooth (Bluetooth Receipt Printing)
- เชื่อมต่อเครื่องพิมพ์กระดาษความร้อนพกพา (58mm / 80mm) ผ่าน **Web Bluetooth API (ESC/POS)**
- พิมพ์ใบแจ้งหนี้ค่าน้ำประปาหรือใบเสร็จรับเงินได้ทันทีหลังจากบันทึกเลขมิเตอร์ (รวมถึงขณะ Offline) พร้อมโหมดพิมพ์ผ่านหน้าเว็บมาตรฐาน (`window.print()`)

### 3.6 ระบบตรวจสอบค่าน้ำสำหรับเจ้าของบ้านผ่าน LINE LIFF (Resident Portal)
- เจ้าของบ้านเข้าใช้งานผ่าน LINE LIFF ผูกบัญชีด้วย `line_user_id` หรือค้นหาด้วยเลขมิเตอร์/บ้านเลขที่
- แสดงรายการบิลค่าน้ำ (รอชำระ / ชำระแล้ว), รายละเอียดการคำนวณแต่ละขั้น, รูปถ่ายมิเตอร์น้ำ และใบเสร็จรับเงินอิเล็กทรอนิกส์

## 4. ตัวชี้วัดความสำเร็จ (Success Metrics)
1. **Offline Reliability:** บันทึกมิเตอร์และพิมพ์บิลผ่าน Bluetooth ขณะไม่มีอินเทอร์เน็ตได้ 100% และซิงค์ข้อมูลกลับโดยไม่เกิดบิลซ้ำ (`0 duplicate invoices`)
2. **Speed of Field Operation:** ลดเวลาการจดมิเตอร์และออกบิลต่อหลังคาเรือนเหลือไม่เกิน 30 วินาที
3. **Security Compliance:** Token ที่กด Logout แล้วต้องถูกปฏิเสธ (`401 Unauthorized`) ทันที 100% ผ่านระบบ JWT Blacklist
